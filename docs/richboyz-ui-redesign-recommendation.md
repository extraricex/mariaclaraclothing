# Richboyz-Inspired Storefront UI Recommendation

## Goal

Use the Richboyz website as a design reference for a more polished streetwear ecommerce experience, while keeping Maria Clara Clothing visually distinct and not copying their exact branding, layout, copy, imagery, or assets.

Reference reviewed: https://richboyz.com/

## What Works Well In The Reference

- Strong commerce header with left navigation, centered brand, and right-side search/account/cart actions.
- Category-heavy navigation for quick shopping paths such as new arrivals, best sellers, tees, hoodies, bottoms, and accessories.
- Product-led homepage sections that show real items, product names, and prices early.
- Search overlay with popular categories and product suggestions.
- Editorial product storytelling sections that mix lifestyle imagery, short copy, and direct product links.
- Category tile grid near the lower homepage to help shoppers browse by product type.
- Footer organized by shopping links, company links, customer service, social links, and email signup.

## Important Boundary

We should not make an exact clone of Richboyz. The better direction is to use the same ecommerce principles:

- dense but clean shopping navigation
- large product imagery
- editorial streetwear rhythm
- quick category browsing
- stronger footer and signup area

Maria Clara should still keep its own Filipino-inspired identity, existing logo, product photography, campaign images, wording, and brand tone.

## Recommended Direction

### 1. Header And Navigation

Upgrade the customer header into a fuller ecommerce navigation system.

Recommended nav:

- Shop
- New Arrivals
- Best Sellers
- T-Shirts
- Oversized Shirts
- Collections
- FAQ

Keep:

- centered Maria Clara logo
- search icon
- profile icon
- cart icon
- mobile drawer

Add:

- dropdown or drawer grouping for categories and collections
- active cart count
- stronger mobile category navigation

### 2. Homepage Structure

Recommended homepage order:

1. Hero campaign image or carousel
2. Horizontal category navigation strip
3. New Arrivals product row
4. Featured product/story section
5. Best Sellers product row
6. Collection banner for Freedom of Mind
7. Category tile grid
8. Community/email signup section
9. Expanded footer

This keeps the page focused on shopping while still giving the brand a lifestyle feel.

### 3. Product Sections

Keep product cards clean and high-confidence:

- large product image
- product name
- price
- available sizes or quick size chips
- sold out state
- quick add button where possible

Recommended sections:

- New Arrivals
- Best Sellers
- Oversized Shirts
- Freedom of Mind
- Back in Stock or Limited Pieces

### 4. Search Experience

Improve the search overlay to feel more useful.

Add:

- popular search links
- suggested categories
- product results with image, name, and price
- “View all products” action

Suggested popular links:

- New Arrivals
- Oversized Shirts
- Black Shirts
- White Shirts
- Best Sellers

### 5. Category Tiles

Add browse tiles near the lower homepage.

Recommended tiles:

- New Arrivals
- Oversized Shirts
- T-Shirts
- Black Collection
- White Collection
- Accessories, if available later

Each tile should use real product or campaign imagery, not abstract graphics.

### 6. Footer

Replace the simple footer with a richer ecommerce footer.

Recommended groups:

- Shop
  - New Arrivals
  - Best Sellers
  - Collections
  - All Products
- Customer Care
  - FAQ
  - Shipping and Returns
  - Terms of Use
  - Contact
- Brand
  - About Maria Clara
  - Freedom of Mind
- Join the Community
  - Email signup
  - Social links

## What I Recommend We Build First

Start with the homepage and shared customer shell, not the product page.

First implementation pass:

1. Header navigation upgrade
2. Category navigation strip below the header or hero
3. Product-led homepage sections
4. Search overlay improvements
5. Category tile grid
6. Expanded footer

Reason: these changes improve the whole storefront immediately and create the structure needed for later collection pages.

## What To Avoid For Now

- Do not copy Richboyz images, text, exact section order, or brand language.
- Do not add international currency/country selector yet.
- Do not add a full account system unless checkout/order tracking is ready.
- Do not add too many collection names until the admin collections workflow supports them.
- Do not make the page visually busy with too many banners.

## Recommended Visual Style For Maria Clara

- Keep a clean white/black base.
- Use campaign photography as the strongest visual signal.
- Keep typography uppercase and direct, but less aggressive than Richboyz.
- Use restrained accent colors from the Maria Clara palette.
- Make product imagery the primary design element.
- Keep buttons simple and high-contrast.

## Suggested Implementation Plan Later

When approved, create a dedicated implementation plan:

- `docs/superpowers/plans/YYYY-MM-DD-richboyz-inspired-storefront-refresh.md`

The plan should include:

- tests for header consistency across all customer pages
- tests for homepage section order
- tests for search overlay popular links and product results
- responsive checks for mobile, tablet, and desktop
- screenshot verification after implementation

## Final Recommendation

Yes, we can move Maria Clara closer to this kind of premium streetwear ecommerce UI. I recommend adapting the shopping structure and visual rhythm, not duplicating the exact design.

The strongest next step is a storefront refresh focused on:

- better navigation
- richer homepage product sections
- better search
- category tiles
- expanded footer

This gives the customer website a more complete clothing-brand feel without disrupting checkout, admin orders, J&T export, or product management.
