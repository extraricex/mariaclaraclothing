# Admin Dashboard Daily Control Center Plan

**Goal:** Improve the admin dashboard so it shows what needs attention today and lets the owner change the date range for dashboard numbers.

**Recommended dashboard direction:** Treat the dashboard as a daily control center, not a large analytics page.

## First Pass

- Add a date range selector: Today, Last 7 days, Last 30 days, All time.
- Apply the selected date range to sales summary, order summary, order charts, recent orders, and shipping totals.
- Add a Today's work panel with:
  - COD confirmation queue.
  - Orders to pack.
  - Orders ready to ship.
  - Low-stock products.
  - Sold-out products.
  - Draft products.
- Add a quick action to Manage collections.

## Later Improvements

- Add collection performance for New Arrivals and Freedom of Mind.
- Add best-selling product/collection once product-level order reporting is stable.
- Hide weak charts when there is not enough order data.
- Add direct action buttons for packing, shipping, and COD confirmation from dashboard cards.
