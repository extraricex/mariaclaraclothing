# FAQ Page

## Route
- `/faq.html`

## Source Files
- `public/faq.html`
- `public/js/shell.js`
- `public/styles.css`

## Purpose
The FAQ page answers common customer questions about Maria Clara Clothing, sizing, payment, delivery, and support.

## Main Sections
- Customer header and announcement bar.
- Mobile drawer and search overlay.
- Policy-style content layout.
- FAQ questions and answers.
- Footer.

## Content Topics
- Brand overview.
- Where products are made.
- Available sizes.
- Payment methods.
- Delivery timelines.
- Support contact.

## Behavior
- Header search and cart count are powered by `shell.js`.
- Page content is static HTML.

## Notes
- This page should visually match the homepage header and icon treatment.
